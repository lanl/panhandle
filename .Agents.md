# Panhandle - Agent Configuration

This file defines the AI agent configurations for the Panhandle project.

## Project Overview

Panhandle is an eBPF-based user activity monitoring tool for HPC environments. It monitors execve syscalls and shell activity (bash/zsh) using the Aya Rust library for eBPF.

## Workflow Commands

### Development
```bash
# Run linting
./scripts/lint

# Update dependencies
./scripts/update

# Build
cd panhandle && cargo build --release

# Test
cd panhandle && cargo test

# Security check
cd panhandle && cargo deny check
```

### Code Quality
- All Rust code must pass `cargo clippy -- -D warnings`
- Code must be formatted with `cargo fmt`
- No `unsafe` code without explicit justification
- All dependencies must pass `cargo deny check`

### Git Practices
- Commit messages follow conventional commits
- All changes must pass CI checks
- No Cargo.lock in gitignore for binaries (already handled)

## Environment

- **Rust**: 2024 edition, nightly toolchain
- **eBPF**: Aya 0.16+, kernel 5.10+
- **Build**: cargo, make
- **Testing**: cargo test, integration tests in `panhandle/tests/`
